# CLAUDE.md

This is the public engineering guide for coding agents working in this repository.
Claude Code loads it directly; `AGENTS.md` directs Codex to read it in full.

## Commands

```bash
pip install -e ".[dev]"   # install with dev extras (pytest + ruff)

pytest -q                                 # full test suite
pytest tests/test_market_routing.py       # one file
pytest tests/test_x.py::Cls::test_y       # one test
RUN_LIVE_DATA_TESTS=1 PYTHON_DOTENV_DISABLED=1 uv run --extra dev pytest -q -m live_data
ruff check .                              # lint (CI runs this repo-wide, strict)

python main.py        # scripted single-ticker run (edit ticker/date in main.py)
tradingagents         # interactive CLI (also: python -m cli.main)
```

CI (`.github/workflows/ci.yml`) runs three jobs on push/PR: `test` (pytest on Python 3.10–3.13), `smoke-install` (bare `pip install .` then import — catches undeclared runtime deps), and `lint` (`ruff check .`). Pytest markers: `unit`, `integration`, `live_data`, `smoke`. Live-data contract tests are opt-in via `RUN_LIVE_DATA_TESTS=1`; default pytest and CI never make those network requests.

`pyproject.toml` uses PEP 621 extras. **Declare runtime deps in `[project.dependencies]`** — the `smoke-install` job bare-imports the package, so an undeclared runtime import fails CI — and dev/test tools in `[project.optional-dependencies].dev`. **Ship non-code data files (e.g. JSON snapshots) via `[tool.setuptools.package-data]`** and load them with `importlib.resources`, not a relative path — an editable install sees the file on disk but a real `pip install .` only bundles registered package-data, and `smoke-install` won't catch the gap because it imports without reading the file.

## Architecture

**Entry point.** `TradingAgentsGraph` (`tradingagents/graph/trading_graph.py`) is the public API; `.propagate(ticker, date)` returns `(final_state, decision)`. Tickers are Yahoo-style exchange-suffixed (`AAPL`, `7203.T`, `0700.HK`); company identity and the alpha benchmark resolve automatically per market via `benchmark_map` in `default_config.py`.

**Agent graph (LangGraph).** Built in `graph/setup.py`, transitions in `graph/conditional_logic.py`, initial state in `graph/propagation.py`, optional resume via `graph/checkpointer.py`. The pipeline mirrors a trading firm: **analysts** (`agents/analysts/`: market, news, sentiment+social, fundamentals) → **researchers** bull/bear debate (`agents/researchers/`) → **research_manager** → **trader** (`agents/trader/`) → **risk debate** aggressive/conservative/neutral (`agents/risk_mgmt/`) → **portfolio_manager** → **reflection** (`graph/reflection.py`, `signal_processing.py`). Analysts run as a configurable subset; the sentiment analyst is special — it does **not** use tool-calling, it prefetches its data sources directly before the LLM call.

**Data vendor layer (`tradingagents/dataflows/`).** This is the most important subsystem to understand before touching data code. Analyst tools (`agents/utils/*_tools.py`, `@tool`-wrapped) call `route_to_vendor(method, *args)` in `interface.py`, which routes by config:
- `TOOLS_CATEGORIES` groups tools into categories (`core_stock_apis`, `technical_indicators`, `fundamental_data`, `news_data`, `macro_data`, `prediction_markets`).
- `VENDOR_METHODS` maps each method → `{vendor_name: impl_func}`. A method is only servable by a vendor that appears here for it.
- `get_vendor(category, method, market)` resolves the vendor chain: `tool_vendors[method]` → `data_vendors_by_market[market][category]` (suffix routing, see below) → `data_vendors[category]`.
- The configured vendor string **is** the chain (comma-separated for ordered fallback). The router does **NOT** silently fall back to unconfigured vendors (regressions #988/#289). Errors use a typed taxonomy in `errors.py`: vendors raise `VendorNotConfiguredError` (missing key), `VendorRateLimitError`, or `NoMarketDataError` (empty/stale); the router tries the next vendor on each, surfaces `NO_DATA_AVAILABLE` when all report no data, and degrades `OPTIONAL_CATEGORIES` (macro, prediction markets) to a sentinel instead of crashing the run. **When adding a vendor**: write impl functions matching the existing return shapes (stock=CSV str, fundamentals=JSON or formatted str, indicators/macro=markdown str), register them in `VENDOR_METHODS`, and raise the typed errors — do not invent new fallback logic.

**Suffix-based market routing (`dataflows/market_context.py`).** A ticker's exchange suffix (e.g. `.T`, `.SS`) can select a market-specific vendor chain via `data_vendors_by_market` (empty by default = behavior unchanged). Only **ticker-bearing** methods are routed: `infer_market` reads the market from their first positional arg. **Ticker-less** methods (`get_global_news`, `get_macro_indicators`, `get_prediction_markets` — listed in `TICKERLESS_METHODS`) are deliberately **market-agnostic** and always use the default chain — macro is cross-border, so there is no per-run market state and no ContextVar. Suffix detection is the shared `symbol_utils.match_exchange_suffix` (longest-match), also used by `_resolve_benchmark`, so only configured suffixes match and `BRK.B` is never misread. A consequence to keep in mind: routing `news_data` for a suffix sends per-ticker `get_news`/`get_insider_transactions` to that vendor while `get_global_news` stays global.

**Analysis-date enforcement.** Public tools retain their existing signatures for direct callers. The graph binds separate same-name variants for Market, News, and Fundamentals; `InjectedState("trade_date")` hides end/current dates from the model and ToolNode supplies the immutable workflow date. Ticker news additionally derives its configured start date in the tool itself. Live-only graph sources must gate before routing: Polymarket returns an explicit unavailable sentinel for historical runs, and current-snapshot fundamentals providers such as Alpha Vantage `OVERVIEW` follow the same rule. Keep the analyst binding and its executor ToolNode on the same graph-only variant whenever a dated tool is added.

**Identity and ticker-news quality.** `dataflows/instrument_identity.py` owns the shared, cached identity resolver. No-date/near-live calls may use rich yfinance `.info`; historical calls use exact-symbol `yf.Search` only and never backfill missing sector/industry from current data. `dataflows/news_quality.py` is a hybrid evidence layer, not a natural-language judge: it applies date/source/template boundaries, builds NFKC/casefolded aliases, and labels explicit ticker or full/multi-token company-name evidence `[direct]`; bare tickers, single-word/derived brands, and summary-only mentions become `[candidate]` for the existing analyst LLM to accept or reject. `[context]` remains external industry/market background, and known junk/templates, duplicates, and items with no entity evidence are dropped deterministically. Entity-distinguishing `Group`/`Holdings` suffixes are preserved, and Yahoo filtering carries both the user symbol and its canonical query symbol. Yahoo ticker news overfetches before filtering, uses timezone-aware publication timestamps and the exchange-local calendar for supported suffixes (`.T`, `.HK`, `.SS`, `.SZ`, `.NS`, `.BO`, `.L`, `.TO`, `.AX`; New York for unsuffixed US securities and UTC for crypto), normalized-title dedupe, and final cap; global Yahoo news uses UTC and is deliberately not entity-filtered. Analyst prompts forbid treating candidate/context material as a company event without explicit evidence in the supplied item. The configured ticker-news offset defaults to 14 (15 inclusive dates); News Analyst must call that recent window first and can explicitly replace it with an extended window whose baseline is 90 dates and which never shortens a longer configured recent range, while the injected analysis date remains immutable. Sentiment keeps recent ticker news, social defaults to 7 days, and global news defaults to 7 days.

**Config system.** `default_config.py` is the single source of truth. `DEFAULT_CONFIG` is built through `_apply_env_overrides`, which maps `TRADINGAGENTS_*` env vars (table `_ENV_OVERRIDES`) onto config keys with type coercion. Runtime overrides go through `dataflows/config.py::set_config`, which **deep-merges dict-valued keys one level** (so a partial `data_vendors` update keeps sibling keys) but replaces scalars. Tests hard-reset via `config_module._config = deepcopy(DEFAULT_CONFIG)` because `set_config` merges.

**LLM clients (`tradingagents/llm_clients/`).** `factory.py` builds a provider client from config; providers (OpenAI, Anthropic, Google, Azure, Bedrock, and OpenAI-compatible servers for xAI/DeepSeek/Qwen/GLM/MiniMax/OpenRouter/Ollama) share `base_client.py`. `model_catalog.py` + `capabilities.py` describe known models and per-provider reasoning/thinking knobs; an unknown model warns but proceeds.

**Chinese-market low-frequency evidence (`dataflows/cn/`).** CNINFO announcements and Eastmoney research use a shared 90-inclusive-date candidate window keyed by ticker and exact analysis cutoff, then slice locally for each caller. Their bounded 15-minute memory cache coalesces News/Sentiment requests with the same cutoff but never reuses data fetched for a later cutoff. The sentiment rating block directly parses Sina's per-stock institutional-rating HTML as primary and uses Eastmoney research only when Sina fails or has no qualifying publication-date-filtered rows. Eastmoney's structured major-shareholder/executive feeds remain primary for holding changes; exact-code CNINFO announcement titles are queried only when either structured feed fails. These source choices and fallback reasons travel as structured provenance. Do not add the broader THS holdings pages without first defining passive-fund filtering, event deduplication, and historical PIT rules.

**Japanese-market data (this fork, `dataflows/jp/`).** `.T` tickers route to a JP vendor stack wired through the suffix-routing mechanism above (`data_vendors_by_market[".T"]` in `default_config.py`) — no upstream behavior changes when the map is empty. Historical runs fail closed for live-only sources; the shared 5-day gate lives in `dataflows/lookahead.py` and is compatibility-re-exported from `jp/lookahead.py`. By category:
- **Prices & indicators** — `jquants.py` (J-Quants API **v2**, `x-api-key` auth; OHLCV via `/equities/bars/daily`) with `jquants_indicator.py`; yfinance stays a keyless fallback. `get_verified_market_snapshot` is in the same `technical_indicators` vendor category, uses the selected vendor's adjusted OHLCV/warm-up path, and labels the actual source after fallback.
- **Fundamentals** — two per-method **assemblers**: `jp_fundamentals.py` (J-Quants `/fins/summary` + disclosure-date-safe computed valuation ratios, TOPIX-weekly beta, dual-mode forward) serves `get_fundamentals`; `jp_statements.py` serves the three statement methods with deduplicated, accounting-basis-labelled J-Quants summaries plus curated yfinance line items only for near-live runs. Historical `.T` statements never request yfinance because its current frames expose fiscal period ends but not point-in-time filing timestamps; the direct yfinance fallback enforces the same boundary. Graph-facing tools hide `curr_date` from the LLM and inject `AgentState.trade_date`, while direct no-date calls preserve explicitly labelled live-retrieval compatibility. Each assembler serves only its own methods, so the router picks the right one per method. US yfinance statements remain available with explicit period-end-only / non-point-in-time labels.
- **News** — `jp_news.py` is a multi-source **assembler** (the router is first-success fallback, so a plain chain can't keep sources side-by-side): EDINET statutory filings (`edinet_news.py`) + TDnet 適時開示 (`tdnet_news.py`) + Google-News-RSS media (`google_news.py`, company name resolved via `company_info.py` off J-Quants `/equities/master`). Recent calls share the configured window; a manual extended call uses at least 90 inclusive dates without shortening a longer configured range. Google receives that full graph range, EDINET remains capped to 90 dates, and TDnet is clamped to its actual free rolling 31 dates. Google applies the shared entity/finance-context classifier after JST date filtering, hard-drops Mshale, Yahoo AI/quote templates, and 日経会社情報DIGITAL disclosure/governance mirrors, then normalized-title dedupes before the configured cap. For `.T` tickers, News also receives J-Quants `/equities/investor-types` as explicitly market-level regional context: the as-of market section is resolved through `/equities/master` (`0111`/`0112`/`0113`), never defaulted to Prime, and must not be attributed to the ticker. `get_global_news` stays market-agnostic.
- **Sentiment** — prefetched (the sentiment analyst does not tool-call): per-stock J-Quants margin/short data, 90-date EDINET 大量保有 / 公開買付 TOB filings (`edinet_holdings.py`), and live-only analyst ratings. Market-wide investor flows are deliberately excluded. EDINET's per-date all-market document lists use a shared 180-date memory LRU plus bounded gzip disk cache for news/holdings and all tickers; the Tokyo calendar date decides settlement, and the still-changing current day has only a short memory TTL. Target matching uses a ticker→EDINET-code map (`edinet_code_map.py`) that ships a committed seed snapshot and **self-heals** while scanning `documents.json`. US StockTwits/Reddit are skipped for historical trade dates and are date-window-filtered for near-live runs.
- **Macro** — cross-border and market-agnostic (US + JP + China pulled together): `fred.py`, `estat.py` (e-Stat), `boj.py`, `jp_macro.py` (MOF JP10Y with FRED fallback), and keyless `cn_macro.py` (NBS recent-release primary plus Eastmoney/SAFE/ChinaMoney fallbacks). All share `macro_common.SeriesCache`, an in-memory LRU plus an opt-in **cross-run disk layer** (namespaced fred/estat/boj/jp/cn) that is look-ahead-safe by key, settle-gated with a grace window, TTL-refreshed, and file-count-bounded. MOF raw CSVs additionally use source-aware caching: the current-month file expires at the next expected 09:30 JST government-business-day publication boundary, while settled history has a 30-day cap. Missing FRED credentials disable only FRED-owned cells; China, MOF, BOJ, and configured e-Stat cells still render independently. China CPI/GDP/PMI prefer bounded official NBS release pages with separate release-date/observation-period metadata; GDP preserves cumulative year-to-date YoY. If a recent official page is not discoverable, those three aliases fall back to observation-period-filtered non-vintage Eastmoney data. NBS unemployment intentionally remains latest-release coverage.

Shared JP HTTP retry/backoff lives in `jp/http_util.py`; the trading calendar (JPX holidays) in `jp/calendar.py`.
